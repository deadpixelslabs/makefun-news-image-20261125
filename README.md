# The World Today · 25 November 2026

An original illustrated international news front page. Its lead is Shenzhou-24 carrying Tiangong's first foreign crew member, with three dispatches about an airstrike in Gaza City, housing in Spain's election debate, and Pyongyang ordering a Swiss diplomat to leave.

## Run it

Use Node.js 22.18 or later.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

The offline program writes one image as `entry.png`. Make.fun permits JPEG bytes under that filename. The original editorial illustration is AI-generated. The news captions describe reporting, and the scenes are illustrations.
